# Classification-de-symboles-avec-r-seau-de-neurones
n projet simple de machine learning utilisant PyTorch pour entraîner un réseau de neurones fully connected afin de classer des symboles * et /. Le dataset est généré automatiquement, les symboles sont encodés en vecteurs one-hot, et le modèle est évalué avec une précision mesurée sur un jeu de test.
